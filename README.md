# Fly Survival Helper

[Русский](README.ru.md) | **English**

An offline field reference and survival assistant that combines local search and language models with a mobile Android/Termux workflow.

## Included in this repository

- Python assistant for searching local reference collections and retrieving supporting passages.
- Includes a mushroom-safety module, image recognition assets, document indexing, and an Android app.
- The mobile workflow and engineering notes are documented in `README_PHONE.md` and `ANDROID_PLAYBOOK.md`.

## Getting started

For the Android workflow, copy the project to the phone, open it in Termux, and follow `README_PHONE.md`. The first setup downloads model/runtime components and requires free storage and network access.

## Notes

Answers depend on the selected local sources and model. Treat mushroom and survival guidance as reference material and verify safety-critical decisions with qualified sources.
