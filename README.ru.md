# Fly Survival Helper

**Русский** | [English](README.en.md)

Офлайн-помощник для полевых справок и выживания: локальный поиск и языковая модель с запуском на Android через Termux.

## Что находится в репозитории

- Python-помощник ищет по локальным справочникам и показывает найденные фрагменты источников.
- В репозитории есть модуль безопасности грибов, материалы для распознавания изображений, индексирование документов и Android-приложение.
- Инструкция для телефона и технические заметки находятся в `README_PHONE.md` и `ANDROID_PLAYBOOK.md`.

## Запуск и настройка

Для запуска на Android скопируйте проект на телефон, откройте его в Termux и следуйте `README_PHONE.md`. Первая установка загружает модель и компоненты среды, поэтому нужны свободное место и интернет.

## Примечания

Ответы зависят от подключённых локальных источников и модели. Сведения о грибах и выживании используйте как справочную информацию; решения, связанные с безопасностью, проверяйте по надёжным источникам.
