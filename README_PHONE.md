# Приложение выживания — установка на телефон (2 шага)

Целевая машина: Android (проверено под Termux), 8+ ГБ RAM, ~2.5 ГБ свободно.
Тестовая: Nothing Phone 2a (12 ГБ RAM).

## Шаг 1 — скопировать папку проекта на телефон

Любым способом: USB-кабель, Syncthing, SD-карта, отправка себе в мессенджер
(архивом) → распаковать в `~/survival/` (Termux: `tar xzf` или файловый
менеджер + `termux-setup-storage`).

В папке должны быть:
- `flybrain/` — код
- `models/mobilenet_v3_small.onnx` — модель зрения (3.7 МБ)
- базы (папки `plants_db/ fungi_db/ poisonous_db/ nature_db/` — по желанию)

## Шаг 2 — один скрипт установки

```bash
pkg install termux-api   # опционально (не обязательно)
cd ~/survival
bash install_termux.sh   # пакеты + LLM 1.1 ГБ + llama.cpp (~10 мин первый раз)
```

## Запуск

```bash
./run.sh
```

Откроется русский диалог. Дальше каждый день — одна команда.

Первый запуск внутри диалога (один раз):
```
индексируй виды plants_db
индексируй виды fungi_db
индексируй виды poisonous_db
индексируй виды nature_db
сохрани field_state
```

## Использование

| Команда | Что делает |
|---|---|
| `как выглядит борщевик?` | текстовый поиск по карточкам |
| `распознай: /путь/фото.jpg` | фото → вид → совет (с ☠-предупреждениями) |
| верно / забудь | дообучение выдачи под ваши находки |
| что знаешь / источники | содержимое памяти |
| новая тема | сброс контекста диалога |

## Веб-интерфейс с камерой (альтернатива CLI)

Вместо последней строки в `run.sh` запустите:
```bash
python flybrain/webui.py --llama http://127.0.0.1:8081 --port 8321
```
и откройте в браузере телефона `http://127.0.0.1:8321` — кнопка выбора фото,
вердикт, советы, «верно/забудь».

## Безопасность (важно)

- Предупреждения «⚠️ ЯДОВИТ» / «⚠️ СЪЕДОБНОСТЬ НЕИЗВЕСТНА» выводит
  детерминированный код ДО ответа LLM — модель не может их убрать.
- Грибы: приложение сознательно НЕ угадывает съедобность по фото
  (измерено: невозможно надёжно). Только карточка вида со съедобностью.
- При cos < порога или малом отрыве видов — вердикт не выдаётся
  («не уверен — не употребляй»).
- LLM отвечает строго по одной карточке; нет карточки — «не рискуй».

## Ресурсы

| Компонент | RAM | Диск |
|---|---|---|
| LLM Qwen2.5-1.5B-Q4 | ~2 ГБ | 1.1 ГБ |
| Поисковик + индексы | ~0.5 ГБ | ~5 МБ + базы |
| Итого | ~2.5–3 ГБ | ~2.5 ГБ |

## Ограничения

- Распознавание требует ~50+ фото на вид (измеренная кривая точности).
- Скорость LLM на Phone 2a: ожидается 3–8 ток/с (совет за 3–8 с).
- Первый запуск `install_termux.sh` собирает llama.cpp ~10 минут.
