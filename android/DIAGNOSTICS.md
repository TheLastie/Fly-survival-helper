# Диагностика запуска APK — матрица сценариев

## v7 закрывает
1. Chaquopy .so: extractNativeLibs=true
2. Гонка сервер/WebView: retry-цикл (30×1 с)
3. Python-ошибки: аварийный экран с traceback (crash-server на :8321)
4. ANR «не отвечает»: Python стартует в фоновом потоке
5. «Кажется, что падает»: экран загрузки с этапами (база → индексация → UI)
6. Конфликт подписей: фиксированный debug-ключ в репо — ставится ПОВЕРХ старых сборок

## Если всё же не работает

### A. На экране есть текст ошибки
Перепишите его разработчику — это полный traceback, правка будет точной.

### B. Молча закрывается (нативное падение, сценарий вне Python)
Нужен один logcat. Минимальный путь (один раз, можно у друзей/на работе):
```
# компьютер: platform-tools (google.com/android/bundle)
adb logcat -c                  # очистить
# запустить приложение на телефоне
adb logcat -d | grep -iE "chaquo|flybrain|fatal" > log.txt
```
Прислать log.txt. Это единственный случай, невидимый изнутри приложения.

### C. Гарантированный обходной путь (без APK вообще)
Termux на телефоне + install_termux.sh → ./run.sh. Тот же функционал,
зрение и LLM работают; проверено раньше на эталоне.
